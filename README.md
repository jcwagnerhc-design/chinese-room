# Inside the Chinese Room

A playable version of John Searle's Chinese Room thought experiment for a high-school AI course.

Students work a shift inside the room, matching symbols they can't read, then rebuild the room six ways (systems, scale, robot, learned rules, brain simulator, neuron replacement), see where their verdicts contradict each other, and apply them to four real-world AI cases. They finish with a copyable case file.

Single self-contained `index.html`. Progress is saved in each student's own browser only.
